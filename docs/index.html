TaskCanvas

タスクをすばやく整理し、いつでも確認。

3つの表示モード

ウィジェット

デスクトップで、タスクをツリー表示。サブタスクも展開して一目で確認。

メニューバー

アイコンからポップアップを開き、タスクの追加と完了チェックをすばやく実行。

通常アプリ

リスト切り替え、詳細編集、期限設定、サブタスク作成などフル機能のワークスペース。

主な機能

  • Google アカウントでログイン、複数のタスクリストに対応
  • タスクの追加・完了・削除・メモ編集
  • 期限（due date）の表示と設定
  • サブタスクの作成
  • 完了済みタスクの表示／非表示切り替え
  • フォントサイズや表示項目のカスタマイズ
  • ⌘N でタスク追加、⌘R でリフレッシュなどのキーボードショートカット
